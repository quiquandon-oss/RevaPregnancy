# Crave & Care

A calm, supportive companion app for pregnant individuals — instant craving dispatch to partners/support network, and simple energy & comfort tracking with appointment prep.

This project is being built with [GitHub Spec Kit](https://github.com/github/spec-kit). See
`.specify/memory/constitution.md` for the project's ground rules, and the `specs/` directory
(created as features are specified) for the detailed design.
